# 阶段 09 · 适老化模式（简约浏览 + 全局字体放大 + 路线适老标注）

> 依据《大创申报书 10.3》：
> - 「针对老年群体，在小程序中设置**简约浏览模式与全局字体放大功能**，路线设计中**标注沿途休息座椅、无障碍设施与老年友好路段**」
> - 「通过『**一条路线、多层适配**』的设计理念，让不同年龄、不同需求的游客均可获得舒适的文化体验」
> - 技术路线第 ⑧ 项：「实现适老化模式（字体切换）」
>
> 前置：阶段 01（设计系统）必需；建议在 04（字体设置）与 03（路线详情）之后做。不改任何页面的信息结构，只切换显示密度与尺寸。

---

## 1. 目标

1. 「我的」页提供**一键适老模式**开关，开启后**全局立即生效**、杀进程重进仍保留。
2. 适老模式 = 三件事一起做，缺一不可：
   - **更清楚**：字号放大到 `--fs: 1.3`、正文行高 1.9、字重 500、前景色加深；
   - **更好点**：所有点击区 ≥112rpx、按钮/输入框高度 +16rpx、TabBar 文字放大；
   - **更少干扰**：隐藏装饰插画与细碎信息、关掉非必要动效、地图 marker 放大。
3. 路线详情页与走街页显示**适老设施**（休息座椅 / 无障碍 / 坡道 / 卫生间 / 遮阴），开启模式时图标与文字同步放大。
4. 与既有「字体设置」（阶段 04）**不打架**：适老模式接管字号期间，字体页滑块禁用并给出说明；关闭后自动恢复用户原来的字号。

## 4. 详细要求

### 4.1 开关与状态

- 位置：`pages/profile` 菜单第 6 行「适老化模式」，右侧 `<switch>`（`color="#1A91FA"`，`checked="{{elderMode}}"`）。
- 切换：`app.setElderMode(on)` → 写 `byxz_elder_mode` → 立即重算当前页根节点 class → `wx.showToast`（开：「已开启适老化模式」；关：「已恢复标准模式」）。
- 冷启动：`app.onLaunch` 的 `restoreElderMode()` 在 `restoreFontScale()` 之前跑，保证首帧就是适老尺寸，不闪一下。
- 不做「根据年龄/系统字号自动开启」——误判代价大；只提供手动开关，并在「我的」页开关下方加一行说明。
- 若同时打开系统「大字号」，以小程序内适老模式为准（`--fs:1.3` 已足够）。

### 4.2 视觉覆盖（`app.wxss`，只加不改）

```css
/* 适老模式：只覆盖变量与少量尺寸，不新增 Token */
.elder {
  --fs: 1.3;                 /* 正文 28 → 36.4rpx */
  --ink: #1A1A1A;            /* 比默认 #333 更深 */
  --ink-2: #4A4A4A;
  --ink-3: #6B6B6B;          /* 默认 #999 在米色底上偏淡 */
  --line: #C9BBA6;
  --tap-min: 112rpx;
}
.elder .t-body { line-height: 1.9; font-weight: 500; }
.elder .t-aux  { line-height: 1.7; }
.elder .tap    { min-width: 112rpx; min-height: 112rpx; }
.elder .btn, .elder .cta, .elder .field .input { min-height: 104rpx; }
.elder .deco { display: none; }              /* 装饰插画/纸屑/时间轴细线 */
.elder .fade-up { animation: none; }
.elder .card  { border-color: #C9BBA6; }
```

- **必须**只覆盖变量与尺寸，不新增色值 Token；`--fs` 由 `app.getPageStyle()` 注入，`.elder` 里的 `--fs` 作为兜底。
- 装饰元素统一加 `class="deco"`（探索页拼贴头、走街页路牌与定位插画、我的页水彩封面叠层、纸屑动画）——阶段 09 只给它们加类名，不删结构。
- 动效降级：`animation: none` 只作用于 `.elder` 作用域；页面切换的 `fade-up` 保留 0 位移也可，但不得高于 120ms。

### 4.3 点击区与可读性

- 所有可点元素（卡片、按钮、TabBar 项、菜单行、胶囊）在 `.elder` 下点击区 ≥ **112rpx**；小图标必须外包 `.tap`。
- 菜单行高 112 → **128rpx**；TabBar 高度 112 → **128rpx**（`.elder` 下 `custom-tab-bar` 同步加高，页面 `padding-bottom` 要跟着加 16rpx）。
- 表格/键值对（建筑小档案）在 1.3 字号下若两列挤压，`.elder` 下改为**单列**（`grid-template-columns: 1fr`）。
- 长文正文首行缩进保留，行距 1.9；不做两端对齐（大字号下会产生大空隙）。

### 4.4 地图与路线（「一条路线、多层适配」）

- 地图 marker：`.elder` 下 `width/height` 放大约 1.35 倍（`56×72 → 76×96rpx`），`iconPath` 不变。
- POI 卡 / 点位卡：标题 32 → 36rpx，按钮文字 28 → 32rpx，卡高自动（不写死）。
- 路线详情时间轴：每站追加一行设施图标 + 文案（「有座椅」「无障碍入口」「有坡道」「有卫生间」「有遮阴」），无设施则整行不渲染。
- 走街进行中：顶部信息条追加「下一处休息点 120m」；没有休息点则显示「全程无设置休息点，请注意体力」。
- 数据来源：`Site.facilities`（见 §4.6），缺失视为空数组，不报错。

### 4.5 与字体设置（阶段 04）的关系

| 场景 | 行为 |
| --- | --- |
| 适老关闭 | 字号 = `byxz_font_scale`（0.9—1.3），字体页可自由调 |
| 适老开启 | 字号固定 1.3；字体页滑块与三档按钮置灰不可点，顶部说明「适老化模式已接管字号，关闭后可自由调整」 |
| 适老关闭后 | 回到用户原值（`byxz_font_scale` 全程未被适老模式改写，所以天然恢复） |
| 两个都开 | 以适老为准（1.3），字体页只显示当前值 |

- **禁止**适老模式写入 `byxz_font_scale`——否则用户关掉适老后字号回不去。

### 4.6 数据模型增补（向后兼容）

`Site` 追加（可缺省，缺省视为 `[]`）：

```js
facilities: ['seat', 'accessible', 'ramp', 'toilet', 'shade']
// seat 休息座椅 / accessible 无障碍入口 / ramp 坡道 / toilet 卫生间 / shade 遮阴处
```

- 图标：优先 `assets/icons/facilities/<key>.png`（48×48）；文件缺失时降级为**文字胶囊**（「座椅」「无障碍」…），不得出现裂图。
- Mock 要求：12 条点位里至少 6 条含 `seat`、4 条含 `accessible`、2 条含 `toilet`；不得所有点位都填同一套（答辩演示需要差异）。

### 4.7 文案（逐字）

| 位置 | 文案 |
| --- | --- |
| 菜单行 | 适老化模式 |
| 菜单行说明 | 更大字号、更大按钮、更少干扰 |
| 开关 Toast（开） | 已开启适老化模式 |
| 开关 Toast（关） | 已恢复标准模式 |
| 字体页说明 | 适老化模式已接管字号，关闭后可自由调整 |
| 走街信息条 | 下一处休息点 120m ／ 全程无设置休息点，请注意体力 |
| 设施文案 | 有座椅 / 无障碍入口 / 有坡道 / 有卫生间 / 有遮阴 |

## 6. 约束与禁止

1. 不新增路由、不删区块；适老只改变「显示密度与尺寸」，不改变信息架构。
2. 不新增色彩 Token；只覆盖既有变量（`--fs`/`--ink`/`--ink-2`/`--ink-3`/`--line`）。
3. 不得用 `transform: scale()` 整体缩放页面——会糊、会错位、点击热区对不上；必须走字号与尺寸。
4. 不得让适老模式写 `byxz_font_scale`。
5. 不得删掉插画 DOM，只加 `deco` 类隐藏（关闭适老后要能恢复）。
6. 设施图标缺失时必须降级为文字胶囊，不得留空 `src`。
7. 不改 `project.config.json`、不改 18 个 Token 的默认值。
