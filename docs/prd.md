## 1. 产品概述

### 1.1 产品定位

一座「可走、可读、可收藏」的**线上地方史博物馆**。用一张手绘地图，把散落在**广东汕头·小公园开埠区·外马路历史文化街区**的开埠建筑、侨批记忆、红色旧址串起来，让用户边走边读。

- **不是**通用旅游攻略，**不是**城市导览工具集；一切内容围绕「外马路这一片」的可考史料。
- 交互主语是「走」与「读」：地图用来找，史料用来读，路线用来走，打卡用来留下足迹。

### 1.2 目标用户

| 人群 | 典型诉求 | 对应功能 |
| --- | --- | --- |
| 18—35 岁城市漫游者 | 周末去哪儿、怎么走、拍到什么 | 探索地图、Citywalk 路线、走街模式 |
| 返乡青年 / 本地居民 | 重新认识家乡，找回记忆中的点位 | 今昔对照、AI 复原影像、收藏 |
| 亲子家庭 / 研学团队 | 边走边讲，有据可依 | 史料详情、语音讲解、专题聚合 |
| 文史爱好者 | 想读细节、想核年代 | 建筑小档案、老照片、专题 |

### 1.3 核心价值与闭环

```
探索发现 → 查看史料 → 到达点位 → 打卡 / 收藏 → 形成足迹 → 我的成就
```

- 每一步都必须有可点、可回、可留痕的落点，不允许出现「读到一半断了」的断头路。

### 1.4 内容基调

旧纸、朱砂、老照片、手绘插画；**温暖、克制、有年代感**。明确排除：科技蓝紫渐变、玻璃拟态、纯线性单色图标、Material 默认组件感。

**导航规则**

- Tab 间切换 `wx.switchTab`；页面返回 `wx.navigateBack`。

- 未登录触发「打卡 / 收藏 / 走街开始 / 查看我的数据」时：写 `redirect` → 跳登录页 → 登录后原路回跳；无 `redirect` 时回「我的」。

## 5. 关键业务规则

1. **打卡半径**：≤200m 可打卡；≤50m 自动提示；定位精度 >100m 提示「信号较弱，请稍后重试」。
2. **打卡计数**：同一点位每天最多计 1 次；「打卡数」为累计次数，「足迹数」为去重点位数。
3. **收藏**：乐观更新，失败回滚；收藏数展示做 k 格式化。
4. **浏览数**：同设备同一天同一点位只上报一次。
5. **登录拦截**：打卡、收藏、走街开始、我的数据必须登录；浏览与搜索不需要。
6. **字体缩放**：`--fs` 全局生效，范围 0.9—1.3，步进 0.05；切换后当前页立即生效，重进仍保留。
7. **定位**：只在探索页、详情页、走街页按需请求；不在后台持续定位。
8. **AI 复原**：必须标注「AI 生成 / 仅供想象」，不得暗示历史真实性；不做人脸。
9. **分享**：史料、路线、打卡海报均可分享；分享标题带「埠影寻踪」。
10. **内容合规**：昵称、简介做敏感词过滤；无公开 UGC 评论区，降低审核风险。

## 8. 平台能力与合规

| 能力 | 要求 |
| --- | --- |
| 定位 | `app.json` 声明 `permission.scope.userLocation.desc = "用于展示附近史迹并验证到点打卡"` 与 `requiredPrivateInfos: ["getLocation","chooseLocation","startLocationUpdate"]`；首次前用半屏说明用途，拒绝后给「去设置」 |
| 隐私 | `wx.requirePrivacyAuthorize` + `__usePrivacyCheck__: true`，接入《用户隐私保护指引》 |
| 登录 | `wx.login` 换 code；头像昵称用 `chooseAvatar` 与 `<input type="nickname">`，**不用** `getUserProfile` |
| 地图 | `<map>` 同层渲染；marker 用本地 PNG；`bindmarkertap` 取 `e.detail.markerId`；禁止 Skyline |
| 分享 | `onShareAppMessage` / `onShareTimeline` |
| 订阅消息 | 模板 ID 未配置时**只写本地状态并提示**，不调用 `wx.requestSubscribeMessage` |
| 版本 | 基础库 ≥3.0.0（`project.config.json` 为 `3.17.0`）；低于 2.32.3 提示升级 |

## 9. 非功能需求

### 9.1 性能

| 编号 | 指标 | 目标 |
| --- | --- | --- |
| NFR-001 | 首屏加载 | ≤3s（4G） |
| NFR-002 | 页面切换 | ≤500ms |

### 9.2 兼容与可用性

- iOS 11+ / Android 6+；微信 7.0+；全面屏、刘海屏不遮挡（状态栏动态计算 + `env(safe-area-inset-bottom)`）。

- 所有可点击元素有视觉反馈；支持系统级无障碍与系统字号适配。

### 9.3 安全与隐私

- 定位、相册等敏感权限先说明用途；本地不存密码等敏感信息；个人信息传输加密。

## 11. 验收口径

### 11.1 主链路（缺一不可）

1. 探索：地图 + 4 色 marker + POI 卡 → 详情 / 打卡 / 收藏。
2. 史料：5 个分类筛选 → 陶土卡 → 详情 → 今昔对比 → 收藏。
3. 走街：4 条路线 → 路线详情（折线 + 时间轴）→ 开始走街 → 到点打卡 → 完成页。
4. 我的：登录 → 统计 / 菜单 → 打卡点 / 收藏 / 设置 → 退出登录。
5. 搜索：关键词 → 结果分组 → 进详情。

### 11.2 质量线

- 微信开发者工具编译无红色报错、无「页面不存在」、无 Skyline 提示、无 npm 构建提示。
- 控制台无未定义变量、无重复 `setData`；Tab 页无横向滚动、TabBar 不遮挡内容。
- 全仓库不出现旧命名（`heritage*` / `street*` / `mine*`）、模板命名（`quickstart` / `goods` / `examples`）、济南地名。
- 页面数据统一走 `utils/api.js`，不得写死统计数字，不得直接 `require('mock/*')`。
- 字体缩放全局生效并持久化；空态 / 骨架 / 失败态齐备。
- README 含运行步骤、Mock 账号、素材替换清单。
