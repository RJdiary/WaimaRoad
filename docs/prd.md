## 1. 产品概述

### 1.1 产品定位

一款以手绘地图为核心载体，融合史料展示、AI修复影像、走街导览等功能的城市历史文化探索微信小程序。旨在通过数字化手段，让用户以沉浸式、互动式的方式了解城市的历史脉络与文化底蕴。

### 1.2 目标用户

- **文化爱好者**：对城市历史、建筑、红色文化、宗教文化等有浓厚兴趣的人群
- **游客与旅行者**：希望深度了解目的地文化底蕴的游客
- **本地居民**：希望重新认识家乡历史文化的本地用户
- **学生群体**：需要历史文化相关学习资料的中小学生及大学生

### 1.3 产品价值

- **文化传承**：将分散的历史文化资源进行数字化整合与呈现
- **沉浸体验**：通过手绘地图、AI修复影像、语音导览等形式提供沉浸式探索体验
- **智能导览**：基于位置的走街服务，帮助用户规划历史文化探索路线
- **知识赋能**：接入AI知识库，为用户提供实时的历史文化答疑服务

### 2.2 探索模块（首页）

#### 2.2.1 功能描述

探索模块作为产品首页，以手绘地图为核心视觉载体，用户可通过地图上的交互元素快速导航至其他功能模块。

#### 2.2.2 功能清单

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
| --- | --- | --- | --- |
| EXP-001 | 手绘地图展示 | 全屏展示城市手绘地图，支持双指缩放、单指拖动操作 | P0 |
| EXP-002 | 分类图标跳转 | 地图上展示不同类别的史料图标（建筑、红色、宗教等），点击后跳转至史料模块对应分类 | P0 |
| EXP-003 | 主题路线入口 | 地图上标注"主题路线"标识，点击后跳转至走街模块 | P0 |
| EXP-004 | 地图全屏放大 | 支持点击进入全屏地图浏览模式 | P1 |

#### 2.2.3 交互流程

```
用户进入探索页
    ↓
查看手绘地图（可缩放、拖动）
    ├─→ 点击史料分类图标 → 跳转至史料模块（定位至对应分类）
    ├─→ 点击主题路线标识 → 跳转至走街模块
    └─→ 点击全屏按钮 → 进入全屏地图浏览
```

#### 2.2.4 验收标准

- 手绘地图加载时间不超过3秒
- 缩放操作流畅，无明显卡顿
- 图标点击热区准确，跳转响应时间不超过500ms
- 支持至少3级缩放比例

### 2.3 史料模块

#### 2.3.1 功能描述

史料模块对城市历史文化资源进行分类展示，包含建筑、红色、宗教等多个类别，并提供AI修复历史影像的特色展示。

#### 2.3.2 功能清单

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
| --- | --- | --- | --- |
| HIS-001 | 史料分类展示 | 以分类标签或卡片形式展示不同类别的史料内容 | P0 |
| HIS-002 | 分类切换 | 支持用户在不同史料分类间快速切换 | P0 |
| HIS-003 | 史料列表浏览 | 每个分类下以列表形式展示史料条目，包含缩略图、标题、简介 | P0 |
| HIS-004 | 史料详情查看 | 点击史料条目进入详情页，展示完整文字、图片、语音等资料 | P0 |
| HIS-005 | AI修复影像展示 | 以独立分类形式展示AI修复后的历史影像与原始影像的对比 | P1 |
| HIS-006 | 影像滑动对比 | 在AI修复影像详情中，支持用户通过滑动方式对比修复前后效果 | P1 |
| HIS-007 | 史料收藏 | 用户可收藏感兴趣的史料内容 | P1 |

#### 2.3.3 分类体系

| 分类名称 | 说明 |
| --- | --- |
| 建筑 | 历史建筑、地标建筑、传统民居等 |
| 红色 | 革命旧址、红色纪念地、英雄人物事迹等 |
| 宗教 | 寺庙、教堂、道观等宗教文化场所 |
| AI修复影像 | AI技术修复后的历史照片、影像资料 |
| 更多分类 | 可根据实际史料资源进行扩展 |

#### 2.3.4 交互流程

```
用户进入史料模块
    ↓
浏览分类导航（建筑 / 红色 / 宗教 / AI修复影像 / ...）
    ↓
选择分类 → 展示该分类下的史料列表
    ├─→ 点击普通史料 → 进入史料详情页
    │       ├─→ 查看文字介绍
    │       ├─→ 浏览图片资料
    │       ├─→ 播放语音讲解
    │       └─→ 点击收藏
    └─→ 点击AI修复影像 → 进入影像对比页
            ├─→ 滑动对比修复前后效果
            ├─→ 查看影像背景故事
            └─→ 点击收藏
```

#### 2.3.5 验收标准

- 分类切换响应时间不超过300ms
- 史料列表支持下拉刷新、上拉加载更多
- AI修复影像对比滑动流畅，无撕裂感
- 史料详情页内容加载时间不超过2秒

### 2.4 走街模块

#### 2.4.1 功能描述

走街模块基于地理位置服务，为用户提供实景走街导览体验，支持路线规划、点位信息展示、多媒体讲解等功能。

#### 2.4.2 功能清单

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
| --- | --- | --- | --- |
| STR-001 | 位置信息获取 | 用户点击地图上的位置点，获取该位置的详细信息 | P0 |
| STR-002 | 路线规划展示 | 提供多条主题走街路线供用户选择，以地图连线形式展示 | P0 |
| STR-003 | 路线切换 | 支持用户在不同主题路线间切换 | P0 |
| STR-004 | 点位多媒体展示 | 点击地图点位后，弹出该点位的地图、图片、简略史料、AI视频、语音等多媒体内容 | P0 |
| STR-005 | 跳转史料详情 | 在点位弹窗中点击"查看具体史料信息"，跳转至史料模块对应详情页 | P0 |
| STR-006 | 返回首页地图 | 在点位弹窗中点击"在地图上查看"，跳转至探索模块首页并定位至对应位置 | P0 |
| STR-007 | 路线进度追踪 | 展示用户当前所选路线的完成进度 | P1 |
| STR-008 | 点位打卡 | 用户到达指定点位后可进行打卡操作 | P1 |

```
┌──────────────────────────────────────┐
│ 点位名称                               │
│ ┌──────────────────────────────────┐ │
│ │  地图缩略图  │  图片展示区       │ │
│ └──────────────────────────────────┘ │
│ 简略史料介绍...                        │
│ ┌──────────┐  ┌──────────┐           │
│ │ AI视频   │  │ 语音讲解 │           │
│ └──────────┘  └──────────┘           │
│ ┌──────────────────────┐  ┌────────┐ │
│ │ 查看具体史料信息     │  │ 在地图 │ │
│ │                      │  │ 上查看 │ │
│ └──────────────────────┘  └────────┘ │
└──────────────────────────────────────┘
```

#### 2.4.4 交互流程

```
用户进入走街模块
    ↓
浏览可选路线列表 → 选择一条主题路线
    ↓
查看路线地图（展示路线连线及点位标注）
    ↓
点击地图点位 → 弹出点位信息卡片
    ├─→ 查看点位地图定位
    ├─→ 浏览点位图片
    ├─→ 阅读简略史料介绍
    ├─→ 播放AI视频
    ├─→ 播放语音讲解
    ├─→ 点击"查看具体史料信息" → 跳转史料模块详情页
    └─→ 点击"在地图上查看" → 跳转探索首页并定位

- 地图加载时间不超过3秒
- 点位弹窗弹出动画流畅，不超过300ms
- 路线切换后地图视角自动适配路线范围

| AI-002 | 问答界面弹出 | 点击悬浮圆圈后，以底部弹出或半屏形式展示问答界面 | P0 |
| AI-003 | 问题输入 | 支持文字输入方式向AI提问 | P0 |
| AI-004 | 回答展示 | 以对话形式展示AI的回答内容 | P0 |
| AI-005 | 历史问答记录 | 保留用户与AI的对话历史，支持查看 | P1 |

```
用户在任意主要页面
    ↓

- 悬浮圆圈支持全屏拖动，不遮挡核心操作区域

## 4. 用户故事

### 4.1 探索地图场景

**角色**：文化爱好者小王
**故事**：小王打开小程序，首页是一幅精美的手绘城市地图。他通过缩放找到了自己感兴趣的区域，看到地图上标注着不同颜色的图标。点击一个古建筑图标后，直接跳转到了史料模块的建筑分类，看到了该建筑的详细介绍。

**验收标准**：
- 用户可通过缩放、拖动操作浏览地图
- 点击地图上的图标可正确跳转至对应史料分类
- 跳转过程有过渡动画

### 4.2 AI修复影像场景

**角色**：历史系学生小李
**故事**：小李在史料模块中选择了"AI修复影像"分类，看到了一系列老照片的修复对比。他点开一张民国时期的街景照片，用手指左右滑动，清晰地看到了修复前的模糊影像和修复后的清晰效果对比，还读到了这张照片背后的历史故事。

**验收标准**：
- AI修复影像分类独立展示
- 支持滑动方式对比修复前后效果
- 展示影像的背景故事

### 4.3 走街导览场景

**角色**：来城旅游的张先生
**故事**：张先生选择了"红色记忆"主题走街路线，地图上展示了一条清晰的游览路线和5个打卡点位。他走到第一个点位时，点击地图上的标记，弹出了点位信息卡片，看到了老照片、听到了语音讲解，还通过"查看具体史料信息"跳转到了更详细的史料页面。

**验收标准**：
- 可选择不同主题路线
- 点击点位弹出信息卡片
- 信息卡片包含地图、图片、文字、语音等内容
- 可跳转至史料详情和首页地图

### 4.4 个人中心场景

**角色**：本地居民刘阿姨
**故事**：刘阿姨使用小程序一段时间后，在"我的"页面看到了自己已经打卡了12个点位，收藏了8篇史料。她觉得文字有点小，进入字体设置将字号调大了一档。她还在隐私设置中关闭了通知推送，只保留了定位权限以便使用走街功能。

**验收标准**：
- 展示用户的打卡、收藏统计数据
- 支持字体大小调节并全局生效
- 支持管理通知、定位等权限授权

## 5. 界面设计规范

### 5.1 设计原则

- **文化调性**：整体视觉风格体现历史文化底蕴，配色沉稳大气
- **手绘质感**：地图、图标等核心元素采用手绘风格，增强人文气息
- **简洁易用**：信息层级清晰，操作路径简短，降低用户学习成本
- **沉浸体验**：减少干扰元素，让用户专注于内容本身的浏览

### 5.2 色彩规范

| 色彩类型 | 色值（参考） | 用途 |
| --- | --- | --- |
| 主色调 | 暖棕色系 | 导航栏、主按钮、强调元素 |
| 辅助色 | 米黄色系 | 背景、卡片底色 |
| 文字色 | 深灰色系 | 主要文字内容 |
| 点缀色 | 暗红色 | 红色文化相关标识 |
| 点缀色 | 暗金色 | 建筑文化相关标识 |

### 5.3 字体规范

| 类型 | 字号（默认） | 用途 |
| --- | --- | --- |
| 大标题 | 20px | 页面标题 |
| 一级标题 | 18px | 模块标题 |
| 正文 | 16px | 主要内容文字 |
| 辅助文字 | 14px | 说明、标签 |
| 小字 | 12px | 时间、次要信息 |

### 5.4 导航规范

- 底部Tab导航：探索（首页）、史料、走街、我的
- 页面内使用顶部导航栏，左侧返回按钮，中间标题
- 支持左滑返回上一页（iOS）

### 5.5 交互规范

| 交互类型 | 规范说明 |
| --- | --- |
| 点击反馈 | 所有可点击元素点击时应有高亮或缩放反馈 |
| 加载状态 | 数据加载时展示Loading动画，不可出现空白页面 |
| 空状态 | 无数据时展示友好的空状态插画及提示文字 |
| 错误状态 | 网络错误、加载失败时展示错误提示及重试按钮 |
| 弹窗规范 | 底部弹窗从下往上滑出，点击遮罩层可关闭 |

## 9. 风险与应对

| 风险编号 | 风险描述 | 影响程度 | 发生概率 | 应对措施 |
| --- | --- | --- | --- | --- |
| RISK-001 | 史料内容数量不足，影响用户体验 | 高 | 中 | 提前规划内容采集计划，优先保证核心区域和热门分类的内容覆盖 |
| RISK-002 | AI修复影像效果不达预期 | 中 | 中 | 提前进行效果验证，准备多套备选方案；先以已有成功案例作为首批展示内容 |
| RISK-003 | 定位精度不足影响走街体验 | 中 | 中 | 采用多源定位融合方案；在明显位置提示用户开启GPS并设置高精度模式 |
| RISK-004 | AI知识库回答准确性不足 | 高 | 中 | 限定问答范围为历史文化领域；接入专业历史文化知识库；对回答结果设置审核机制 |
| RISK-005 | 手绘地图制作周期长、成本高 | 中 | 中 | 分阶段完成地图绘制，优先覆盖核心区域；考虑采用矢量地图+手绘风格渲染的折中方案 |
| RISK-006 | 小程序包大小超限 | 中 | 低 | 采用分包加载策略，非核心功能放入分包；图片、视频等资源使用CDN按需加载 |
