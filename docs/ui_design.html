五、实现标注（Codex 落地时逐条对照）

图片与图标

  • 本页所有照片位是占位规则示意，不是素材：实现用「渐变底 + 建筑名」占位，等待替换。
  • Tab 图标 4 个：指南针（蓝）、三本立书（蓝/青）、小公园亭（紫）、红顶小屋（蓝身红顶）；选中放大 1.06。
  • 禁止线性单色图标、禁止外链图片、禁止网络字体。

必然出现的状态

  • 骨架屏：3 张卡呼吸动画（1.2s，透明度 0.55—1）。
  • 空态：手绘插画 + 一句引导 + 一个按钮。
  • 失败态：整块错误提示 + 重试按钮，不白屏。
  • 加载更多：「已经到底啦」，不再闪烁骨架。

不可偏离的三处

  • 页底色恒为 #FCF7EE，不随系统深色模式变化。
  • 书法标题只用陶土渐变（#C9705A → #B65A44），不用纯色大字。
  • 数字只用琥珀 #F0AD45 + DIN 系字族，不用青绿。

与 Web 原型的边界

  • 本文件可在浏览器直接打开，是 build-web-apps 阶段生成/比对的视觉基线。
  • 原型里好用的视觉效果，只有在能被 WXSS 实现时才允许进入小程序。
  • 不引入 React / shadcn / Tailwind：交付物是原生小程序。
